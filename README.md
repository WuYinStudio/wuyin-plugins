# wuyin-plugins

无音影视插件市场索引。

当前仅包含：

- **B站弹幕** `wuyin.danmaku.bili` `1.1.0`

## GitHub Pages

仓库 **Settings → Pages**：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

启用后市场地址：

```text
https://WuYinStudio.github.io/wuyin-plugins/index.json
```

在无音影视：

```text
插件中心 → 市场 → 填入上面的地址 → 刷新
```

## 文件
